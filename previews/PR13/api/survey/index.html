Survey Operations

Matrix Construction: Survey → ContactMatrix

ContACT.compute_matrix — Function
compute_matrix(survey::ContactSurvey, partition::AbstractPartition;
               population=nothing, weights=nothing)

Compute a contact matrix from survey data over a fixed finite partition.

Entry M[i,j] is the weighted number of contacts reported into group i by participants in group j, divided by the weighted participant mass W_j of group j. A group with no participants gets a zero column.

Relation to coarsening

Building at a fine partition and coarsening along f is guaranteed to give the same matrix as building directly at the coarse partition whenever, within each coarse participant/source fibre J, the attached population is proportional to participant mass:

N_j = λ_J · W_j        for all j ∈ f⁻¹(J)

with λ_J > 0, required only on fibres carrying participant mass — on the others, N is unconstrained. The constant cancels in the derivation, but it must be nonzero; on ContACT's nonnegative population domain that means strictly positive. The condition is per-fibre, so proportionality must hold separately in each one.

This condition is sufficient for every survey and is required for agreement for arbitrary contact-count data. A particular survey may agree without it — for example, when all fine participant groups in a fibre have the same coarse contact profile — but the operations do not guarantee that. A fibre with no participant mass contributes zero source columns on both routes, so the matrix values agree there for any N.

Matrix agreement does not by itself imply agreement of the attached populations. To guarantee agreement of the full ContactMatrix objects under an external N, the direct coarse build should also be given the pushed-forward population f_*N.

With population=nothing, the condition holds automatically because the weighted participant mass W is itself attached as the population. With an external population, it becomes a calibration (post-stratification) condition on the survey weights. Supplying weights alone does not establish it: when weighted sample composition differs from the target population within a fibre, the two routes generally estimate different quantities and need not agree.

Arguments

  • survey: a ContactSurvey with participant and contact data
  • partition: the finite partition to use

Keyword Arguments

  • population: population per partition group to attach to the resulting matrix. If nothing, uses the weighted participant mass computed from the survey.
  • weights: participant column containing sampling weights, or nothing for equal participant weights

Returns

A ContactMatrix{Float64, MeanContacts} giving the mean number of contacts reported by participants in each source group with contacts in each target group.

Example

partition = AgePartition([0, 5, 18, 65])
cm = compute_matrix(survey, partition)

Filtering

ContACT.filter_survey — Function
filter_survey(survey::ContactSurvey; kwargs...)

Filter a survey by participant attributes. Returns a new ContactSurvey with only matching participants and their contacts.

Keyword Arguments

Any column name in participants can be used as a filter. Values can be:

  • A single value: exact match
  • A vector: membership test
  • A function: predicate applied to column values

Examples

# Filter by country
uk_survey = filter_survey(survey, country="UK")

# Filter by multiple countries
euro_survey = filter_survey(survey, country=["UK", "DE", "FR"])

# Filter by age range
adult_survey = filter_survey(survey, part_age=age -> age >= 18)
